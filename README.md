# 墨卷书阁 · 进阶功能版

在原始卡片 UI 基础上增加：角色权限、上传审核、站内通知、阅读批注、章节评论、星级评分。

## 功能

### 角色与权限

| 功能 | 管理员 | 普通用户 |
| --- | --- | --- |
| 用户管理（增 / 修 / 删） | ✅ | ❌ |
| 板块管理（增 / 修 / 删） | ✅ | ❌ |
| 图书管理（增 / 修 / 删） | ✅ | 仅上传、删除自己上传的 |
| 审核读者上传 | ✅ | ❌ |
| 删除任意评论 | ✅ | 只能删自己的 |
| 阅读、批注、评论、打分 | ✅ | ✅ |

- 普通用户上传图书后状态为「待审核」，管理员通过后才会出现在书架。
- 管理员上传的图书直接上架。
- 普通用户只能删除自己上传的图书，不能删除别人的书。
- `admin` 是系统最高管理员；其他管理员不能删除、降级或修改 `admin` 账号。

### 通知

- 管理员收到：新用户注册、读者上传待审核、读者发表评论、读者删除自己的上传。
- 普通用户收到：自己上传作品的审核通过 / 驳回（含驳回原因）。
- 顶部导航「通知」有未读角标，支持全部标记已读。

### 阅读页

- 右侧「我的批注」栏：显示当前章节的批注，点击可定位到原文并短暂高亮。
- 鼠标划选正文文字 → 弹出批注框，可选 5 种颜色，填写笔记；**批注只有本人可见**。
- 每章底部「本章评论」：所有登录用户可发表、可查看全部评论；本人可删自己的，管理员可删任何人的。
- 图书详情页可打 1-5 星，每人每书一票、可修改；页面展示平均分和评分人数。
- 书架 / 搜索卡片上显示平均分。

## 数据库

- 用户名：`root`
- 密码：空（如本机 root 有密码，请修改 `src/db.properties` 的 `jdbc.password`）
- 数据库：`library_db`

首次建库（会重建表）：

```bat
mysql -uroot --default-character-set=utf8mb4 < sql\library_db.sql
```

已有旧库升级（保留数据，新增上传者、状态和四张社交表）：

```bat
mysql -uroot --default-character-set=utf8mb4 < sql\upgrade_social.sql
```

## 运行

1. Eclipse `Import → Existing Projects into Workspace`
2. 选择本目录，确认 `Targeted Runtimes` 勾选 Apache Tomcat v9.0
3. Servers 视图 → `Add and Remove` → 添加本项目
4. 启动 Tomcat
5. 访问：`http://localhost:8080/library-original-empty/`

默认账号：

- 管理员：`admin / admin123`
- 普通用户：`demo / demo123`

## 新增数据表

| 表 | 用途 |
| --- | --- |
| `notification` | 站内通知（接收者、类型、内容、已读） |
| `annotation` | 阅读批注（图书、用户、章节、段落、原文、笔记、颜色） |
| `comment` | 章节评论（图书、章节、用户、内容） |
| `rating` | 图书评分（图书 + 用户唯一，1-5 星） |

`book` 表新增：

- `uploader_id`：上传者
- `status`：`APPROVED` / `PENDING` / `REJECTED`
